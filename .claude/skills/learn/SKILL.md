# learn — 학습 노트 정리

## 인자
- 주제(선택). 생략 시 최근 대화/커밋에서 학습 포인트를 추려 제안.

## 절차
1. 주제를 kebab-case 파일명으로 정한다. `docs/learning/`에 같은/유사 주제 파일이 있으면 새로 만들지 않고 해당 파일에 섹션 추가.
2. 형식:
   ```markdown
   # 주제

   ## 핵심 개념
   ## 이 프로젝트 적용
   - 관련: #이슈, PR, ADR-xxxx, 파일 경로
   ## 삽질 / 주의점
   ## 참고
   ```
3. 사용자가 이미 아는 일반론은 줄이고, 이 프로젝트에서 실제로 부딪힌 내용 위주로 짧게.
4. 참고 링크는 실제 확인한 공식 문서만. 추측 URL 금지.
5. `docs/learning/README.md` 목록 갱신.
6. `commit` 스킬 규칙으로 `docs(learning): <주제>` 커밋.
