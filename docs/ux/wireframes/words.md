## word-list
```
┌──────────────────────────┐
│ ←  단어           [ + ]  │
│ [1급][2급][3급][★즐겨찾기]│
│ 카테고리: [전체 ▾]       │
├──────────────────────────┤
│ 买  mǎi  마이    사다   ☆│
│ 卖  mài  마이    팔다   ★│
│ 看  kàn  칸      보다   ☆│
│ 茶叶 cháyè 차예 찻잎 ☆ 내 단어│
│ ...                      │
├──────────────────────────┤
│ (★ 탭일 때)              │
│ [   즐겨찾기로 퀴즈   ]  │
└──────────────────────────┘
```

- 오류: `불러오지 못했습니다 [다시 시도]`
