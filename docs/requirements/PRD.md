# PRD — HSK Quiz App

- 버전: v0 (2026-09-17)
- 소유: 사용자 (AI는 변경을 제안만 함)
- 입력: [NB.md](NB.md)

## 1. 한 줄 설명
HSK 1~3급 단어로 공부하는 개인용 중국어 퀴즈 앱. **내가 자주 헷갈리는 단어를 기록해 그 단어들을 묶어서** 출제한다.

## 2. 문제와 차별점
- 듀오링고처럼 모두 같은 커리큘럼을 따라가면, 내가 계속 헷갈리는 단어 쌍(예: 买/卖)을 집중해서 연습하기 어렵다.
- 이 앱은 **혼동 관계**(미리 정의한 것 + 내가 퀴즈 중 직접 태깅한 것)와 **내 숙련도**(`mastery_score`)를 함께 써서, 약한 단어를 정답으로 두고 헷갈리는 단어를 보기로 넣어 출제한다.

## 3. 사용자
- 본인 1명(중국어 학습자, 한국어 사용자). 폰(Expo 앱)으로 푼다.
- 구조는 여러 유저를 지원하고, 유저마다 진도·기록을 따로 가진다. 운영자 역할(admin)은 공용 데이터를 관리한다.

## 5. 성공 기준 (MVP)
| # | 기준 | 확인 방법 |
|---|---|---|
| S1 | 폰 앱에서 가입 → 로그인 → 앱을 다시 켜도 로그인 유지 | 실기기 시나리오 |
| S2 | 급수 필터로 단어 목록을 보고, 상세에서 병음·한국어 발음·예문 확인 | 실기기 시나리오 |
| S3 | 커스텀 단어를 추가하면 나에게만 보이고 다른 계정에는 안 보임 | 계정 2개로 확인 |
| S4 | 즐겨찾기를 켜고 끄고, 즐겨찾기만 모아 보고, 즐겨찾기 단어로 퀴즈를 시작 | 실기기 시나리오 |
| S5 | 퀴즈 1세션(10문제)을 끝까지 풀고 결과를 보며, 보기에 혼동 단어가 섞여 나옴 | 실기기 + 시드의 혼동 쌍 확인 |
| S6 | 틀린 단어의 `mastery_score`가 낮아지고, 다음 세션에 더 자주 나옴 | API 응답/DB 조회 |
| S7 | 다른 유저의 세션·통계·즐겨찾기에 접근하면 404 | 자동 테스트 |

## 6. 학습 목표 (이 프로젝트의 중요한 목적)
1. **DB 설계** — 식별자 체계, 외래키, 정션 테이블(자기참조 / M:N), 유저별 데이터 분리
2. **클린 아키텍처 & 디자인 패턴** — 4계층 분리, 의존성 역전, Repository/Strategy/Factory
3. **배포 대비 최소 보안** — 인증/인가, 데이터 접근 제어

## 7. 진행 원칙
- **직접 시나리오 테스트할 수 있는 가장 작은 단위로 구현**하고 점진적으로 확장한다. 한 번에 여러 기능을 묶지 않는다.
- 디자인 패턴은 **필요해진 시점에 리팩토링으로** 도입하고 이유를 ADR로 남긴다.
