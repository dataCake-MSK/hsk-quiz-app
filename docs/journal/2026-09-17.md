## 개발자 퀵 가이드
> 이날 결과로 이어진 진행사항만 압축.

### 핵심 진행사항
1. **로컬 저장소 초기화**: `.gitignore`, README로 main 초기 커밋(빈 저장소 부트스트랩 예외)
2. **문서 브랜치** `docs/bootstrap-requirements`: requirements → architecture → ux → reports 순서로 목적별 커밋
3. **자동화 브랜치** `chore/bootstrap-automation`: `.gitattributes` → CLAUDE.md → 스킬 → Stop 훅 → GitHub 템플릿
4. **Stop 훅 단독 실행으로 확인**: 변경이 있으면 block JSON, `stop_hook_active`면 출력 없음

### 핵심 명령
```bash
git init -b main
git switch -c docs/bootstrap-requirements
git switch -c chore/bootstrap-automation   # main에서 분기
node --check .claude/hooks/stop-vcs-check.js
echo '{}' | CLAUDE_PROJECT_DIR="$PWD" node .claude/hooks/stop-vcs-check.js
echo '{"stop_hook_active":true}' | CLAUDE_PROJECT_DIR="$PWD" node .claude/hooks/stop-vcs-check.js
```

### 핵심 코드·설정
`.claude/settings.json`
```json
{
  "hooks": {
    "Stop": [
      { "hooks": [ { "type": "command",
        "command": "node \"$CLAUDE_PROJECT_DIR/.claude/hooks/stop-vcs-check.js\"",
        "timeout": 30 } ] }
    ]
  }
}
```
