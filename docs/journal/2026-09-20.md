3. **터널 2개 구성**: 앱 화면은 Expo `--tunnel`, 백엔드는 cloudflared 빠른 터널(계정 불필요)
4. **화면 없이 검증**: 로컬 Metro에 번들을 요청해 빌드 성공과 환경 변수 주입을 확인

### 핵심 명령
```bash
npx create-expo-app@latest mobile --template blank-typescript
cd mobile && npm install && npm i -D @expo/ngrok

winget install --id Cloudflare.cloudflared --exact --scope user
cloudflared tunnel --url http://localhost:8000 --no-autoupdate    # https://<랜덤>.trycloudflare.com

# mobile/.env 에 EXPO_PUBLIC_API_URL=<위 주소> 기록 후
npx expo start --tunnel --go --port 8082
curl -s http://127.0.0.1:4041/api/tunnels        # 백그라운드 실행 시 Expo 주소 확인

npx tsc --noEmit
curl -s -o /dev/null -w "%{http_code}\n" "http://127.0.0.1:8082/index.bundle?platform=android&dev=true"
```

### 핵심 코드·설정
`mobile/App.tsx` — 환경 변수가 없을 때와 실패했을 때를 나눠서 표시
```tsx
const API_URL = process.env.EXPO_PUBLIC_API_URL;

async function fetchHealth(): Promise<Status> {
  if (!API_URL) return { kind: "error", message: "EXPO_PUBLIC_API_URL이 설정되지 않았습니다" };
  try {
    const response = await fetch(`${API_URL}/health`);
    if (!response.ok) return { kind: "error", message: `서버 응답 오류 (${response.status})` };
    const body = (await response.json()) as { status?: string };
    return { kind: "ok", status: body.status ?? "unknown" };
  } catch {
    return { kind: "error", message: "서버에 연결할 수 없음" };
  }
}
```
