## 막힌 점
- 8081 포트를 다른 프로젝트의 Expo(이 세션이 띄우지 않은 node 프로세스)가 사용 중 → 끄지 않고 `--port 8082`로 실행. ngrok 검사 API도 4040이 아니라 4041로 밀림
- 백그라운드 실행이라 터미널에 QR·주소가 안 나옴 → ngrok 로컬 API에서 `public_url`을 읽어 해결
- create-expo-app 템플릿이 `LICENSE`·`AGENTS.md`·`CLAUDE.md`·`.claude/settings.json`(Claude 플러그인 자동 활성화)을 만들어 제거
- 폰에서 첫 접속 시 `ERR_NGROK_3200`(터널만 끊김) → Expo 재시작 + 8082를 잡고 있던 잔여 프로세스 정리로 해결
- slowapi에서 `headers_enabled=True`를 쓰면 엔드포인트에 `response` 인자가 있어야 한다(`parameter 'response' must be an instance of starlette.responses.Response`)
- PR #27·#28이 같은 리포트 목록 줄을 고쳐 **머지 충돌** 발생 → 나중 브랜치에 main을 합치고 두 줄을 모두 남겨 해결. 문서 목록처럼 여러 PR이 함께 건드리는 파일은 충돌이 잦다
- CI 첫 실행이 3초 만에 실패: `astral-sh/setup-uv@v10` — 이 액션은 **v10 같은 이동 태그를 제공하지 않는다**. `v10.1.0`으로 고정해 해결(`actions/checkout@v7`, `actions/setup-node@v7`은 이동 태그 있음)
- PostgreSQL을 winget으로 설치하려다 **UAC 승인 창**에서 막힘(원격이라 승인 불가) → 확인해 보니 **PC에 PostgreSQL 17이 이미 설치·실행 중**이었다. 다만 postgres 비밀번호를 몰라 로컬 접속은 보류하고, CI의 postgres 서비스로 검증했다
- DB 연결 실패 테스트가 130초나 걸렸다 → `connect_args={"connect_timeout": 5}`를 주어 5.7초로 단축

### 핵심 코드·설정
`mobile/App.tsx` — 환경 변수가 없을 때와 실패했을 때를 나눠서 표시
```tsx
const API_URL = process.env.EXPO_PUBLIC_API_URL;

async function fetchHealth(): Promise<Status> {
  if (!API_URL) return { kind: "error", message: "EXPO_PUBLIC_API_URL이 설정되지 않았습니다" };
  try {
    const response = await fetch(`${API_URL}/health`);
    if (!response.ok) {
      // 터널은 살아 있고 뒤의 서버만 죽으면 502가 온다 → 연결 실패와 같은 문구로 묶는다
      const unreachable = [502, 503, 504].includes(response.status);
      const message = unreachable ? "서버에 연결할 수 없음" : "서버 응답 오류";
      return { kind: "error", message: `${message} (${response.status})` };
    }
    const body = (await response.json()) as { status?: string };
    return { kind: "ok", status: body.status ?? "unknown" };
  } catch {
    return { kind: "error", message: "서버에 연결할 수 없음" };
  }
}
```

`backend/app/main.py` — 앱을 만들 때 Limiter·CORS를 조립(설정은 환경 변수로만)
```python
def create_app(settings: Settings | None = None) -> FastAPI:
    settings = settings or load_settings()
    app = FastAPI(title="HSK Quiz API", version="0.1.0")
    limiter = build_limiter()
    app.state.limiter = limiter
    app.add_exception_handler(RateLimitExceeded, rate_limit_handler)
    if settings.cors_origins:
        app.add_middleware(CORSMiddleware, allow_origins=list(settings.cors_origins),
                           allow_credentials=False, allow_methods=[...], allow_headers=[...])
    app.include_router(create_health_router(limiter, settings.public_rate_limit))
    return app
```
