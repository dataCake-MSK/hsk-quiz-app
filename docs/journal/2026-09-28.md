## 막힌 점
- `npx expo start --tunnel` → `CommandError: failed to start tunnel / remote gone away` 2회. 포트·잔여 프로세스를 정리해도 동일 → Expo 터널 서비스 쪽 문제로 보고 우회

## 개발자 퀵 가이드
> 이날 결과로 이어진 진행사항만 압축.

### 핵심 진행사항
1. **Expo 터널이 안 될 때 우회 경로 확보**: Metro도 cloudflared로 내보내고 `EXPO_PACKAGER_PROXY_URL`로 공개 주소를 알려준다
2. 순서가 중요하다 — **터널을 먼저 띄워 주소를 얻고**, 그 주소를 환경 변수로 넘기며 Expo를 시작한다
3. 세션을 멈추기 전 **서버 정지 + 포트 확인**을 한 번에 한다

### 핵심 명령
```bash
# 백엔드
cd backend && uv run --env-file .env fastapi dev app/main.py --port 8000
cloudflared tunnel --url http://localhost:8000 --no-autoupdate    # → mobile/.env 의 EXPO_PUBLIC_API_URL

# Metro (Expo 기본 터널이 실패할 때)
cloudflared tunnel --url http://localhost:8081 --no-autoupdate    # → https://<A>.trycloudflare.com
cd mobile && EXPO_PACKAGER_PROXY_URL=https://<A>.trycloudflare.com npx expo start --go
# 폰에는 exp://<A>.trycloudflare.com

# 확인
curl -H 'expo-platform: android' https://<A>.trycloudflare.com/            # 매니페스트 200
curl -o /dev/null -w '%{http_code}' "https://<A>.trycloudflare.com/index.bundle?platform=android&dev=true"
```

```powershell
# 정리: 포트를 잡고 있는 프로세스까지 확인
foreach ($p in 8000,8081,8082,4040,4041) {
  $c = Get-NetTCPConnection -LocalPort $p -State Listen -ErrorAction SilentlyContinue
  if ($c) { Stop-Process -Id $c[0].OwningProcess -Force } 
}
Get-Process cloudflared,ngrok -ErrorAction SilentlyContinue | Stop-Process -Force
```
