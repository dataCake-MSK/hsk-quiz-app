### 핵심 명령
```bash
# GitHub 구성
gh repo create <owner>/<repo> --public --source . --remote origin --push
gh api -X PATCH repos/<owner>/<repo> \
  -F security_and_analysis[secret_scanning][status]=enabled \
  -F security_and_analysis[secret_scanning_push_protection][status]=enabled
gh api -X PATCH repos/<owner>/<repo> \
  -F delete_branch_on_merge=true -F allow_squash_merge=false -F allow_rebase_merge=false
gh issue create --title "[SRS-001] ..." --body-file <파일> --label type:chore --milestone "M0 기반"

# 백엔드 스캐폴딩
uv init backend --app --python 3.12 --no-workspace --vcs none
cd backend
uv add "fastapi[standard]"
uv add --dev pytest ruff
uv run pytest
uv run ruff check .
uv run fastapi dev app/main.py
curl http://127.0.0.1:8000/health        # {"status":"ok"}
```

### 핵심 코드·설정
`backend/app/main.py` — 앱 조립은 팩토리 함수로(테스트에서 새 앱을 만들 수 있게)
```python
from fastapi import FastAPI
from app.interface.routers import health

def create_app() -> FastAPI:
    app = FastAPI(title="HSK Quiz API", version="0.1.0")
    app.include_router(health.router)
    return app

app = create_app()
```

`backend/pyproject.toml` — 테스트 경로와 lint 규칙
```toml
[tool.pytest.ini_options]
testpaths = ["tests"]
pythonpath = ["."]

[tool.ruff.lint]
select = ["E", "F", "I", "B", "UP"]
```
