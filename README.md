# HSK Quiz App

HSK 1~3급 단어로 공부하는 개인용 중국어 퀴즈 앱입니다. 문제를 무작위로 내지 않고, **내가 자주 헷갈리는 단어를 기록해 그 단어들을 묶어서** 출제합니다.

- 백엔드: FastAPI (`backend/`)
- 앱: Expo / React Native (`mobile/`)
- DB: PostgreSQL
